# Medical Image Quality & Disease Detection System

## 📌 Description
A CNN-based medical image analysis system that checks image quality (blur & exposure) and predicts diseases using a trained deep learning model.

## 🚀 Features
- Blur detection  
- Exposure analysis  
- Feature extraction  
- CNN disease prediction  
- GUI interface  

## 🛠 Installation
git clone https://github.com/Tejasri745/project-name.git  
pip install -r requirements.txt  

## ▶️ Run
streamlit run app.py  
or  
python app.py
